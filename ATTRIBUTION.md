# Rider–Waite–Smith tarot images

Artwork: Pamela Colman Smith, directed by Arthur Edward Waite. Originally published by William Rider & Son, 1909.

Downloaded from: https://github.com/sixseeds/tarot-api

Direct source pattern: https://raw.githubusercontent.com/sixseeds/tarot-api/main/cards/{filename}

Reuse information: the source repository explicitly identifies these Rider-Waite (1909) card images as public domain in its README (https://github.com/sixseeds/tarot-api#images). This notice applies to the historical card images; it does not describe ownership of later commercial recolorings or packaging.

The manifest.json file contains each English card name, deterministic local filename, and exact downloaded source URL. The source-cards.json file preserves the repository's original card-name mapping.

No artwork was generated or replaced. For this web distribution, images were resized and converted to WebP for faster loading; the card artwork is unchanged.

Suggested UI credit: “Rider–Waite–Smith · Pamela Colman Smith, 1909 · Public domain” with a source link to the repository.
